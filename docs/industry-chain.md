# 产业链调研：方法与数据

> 目的：给"智能体矩阵按产业链阶段划分"提供**可引用的依据**，而不是拍脑袋定七行。
> 结论先行：**行怎么分，应该由产业关联度决定**；本文给出计算方法和可直接使用的工具。

## 1. 为什么不抄一张"产业链图谱"

网上流传的产业链图谱（"上游—中游—下游"框图）有三个致命问题：

1. **无出处**：说不清数据来源，无法复核；
2. **无权重**：画了连线但不说明强弱，等于没有信息量；
3. **不可复现**：换个人画就是另一张图。

答辩时只要问一句"这两条连线为什么连、强度多少"，二手图谱就答不上来。

**替代方案**：用国家统计局《投入产出表》计算**产业关联度**——有出处、有数值、可复现。

## 2. 方法：投入产出表与关联度系数

### 2.1 从流量表到直接消耗系数

投入产出表给出中间流量矩阵 `x[i][j]`：部门 `i` 的产品有多少被部门 `j` 消耗。
用总产出 `X[j]` 归一化，得到**直接消耗系数**：

```
A[i][j] = x[i][j] / X[j]
```

含义：部门 `j` 每生产 1 单位产品，直接消耗多少部门 `i` 的产品。

### 2.2 完全消耗：列昂惕夫逆矩阵

生产会层层传导（造车要钢，炼钢要电，发电要煤）。完整链条的影响是：

```
L = (I - A)^(-1)
```

`L[i][j]` 的含义：部门 `j` 多生产 1 单位最终产品，对部门 `i` 的**直接+间接**总需求。
这一步是投入产出分析的核心，也是它比"价值链画图"严谨的地方。

### 2.3 影响力系数与感应度系数

| 指标 | 公式 | 含义 | 对应产业链位置 |
|---|---|---|---|
| **影响力系数**（后向关联） | `f_j = Σ_i L[i][j] / (1/n · ΣΣ L)` | 部门 j 增产 1 单位，拉动上游多少 | 越接近**下游/总装**越高 |
| **感应度系数**（前向关联） | `e_i = Σ_j L[i][j] / (1/n · ΣΣ L)` | 全社会各增产 1 单位，部门 i 被拉动多少 | 越接近**上游/基础**越高 |

系数 **> 1** 表示关联度高于全行业平均，是结构性关键节点。

## 3. 数据从哪来

| 层级 | 数据源 | 是否公开 | 用途 |
|---|---|---|---|
| 官方权威 | 国家统计局《中国投入产出表》，153 部门，基准表每 5 年（2018、2023），中间有延长表 | ✅ 公开（[stats.gov.cn](https://www.stats.gov.cn/hd/lyzx/zxgk/202405/t20240524_1953717.html)） | 算关联度系数，确定产业链关键节点 |
| 便捷版本 | `ChinAPIs` R 包内置 2020 年 153 部门投入产出表 | ✅ 公开数据集（[文档](https://rdrr.io/cran/ChinAPIs/man/china_io_2020_153_df.html)） | 免去 Excel 清洗，直接读入 |
| 贸易结构 | 海关总署进出口商品 HS 编码数据 | ✅ 公开 | 看产业的**外向度**（出口占比） |
| 企业级依赖 | 上市公司年报"前五大客户/供应商占比" | ✅ 公开（巨潮/交易所） | 看**企业间**依赖，补充行业级结论 |
| 景气与风险 | 国家统计局月度工业增加值、PMI | ✅ 公开 | 给业务看板提供真实指标序列 |

> 拿不到的是企业内部 ERP/WMS 明细——这部分应明确写进"未来工作"，不要假装有。

## 4. 工具：`scripts/industry_chain.py`

纯标准库实现（不依赖 numpy），可直接对 153×153 的表计算。

```bash
# 用内置示意数据验证算法
python scripts/industry_chain.py --demo --out docs/experiments

# 用真实投产表（CSV：第一行/列是部门名，含一列"总产出"）
python scripts/industry_chain.py --csv data/io_2020.csv --outputs 总产出 --out docs/experiments
```

输出：`{"influence": {...}, "sensitivity": {...}, "top_influence": [...], "top_sensitivity": [...]}`
+ 一份 markdown 表。

**正确性验证**：`tests/unit/test_industry_chain.py` 用 2 部门手算例子校验公式
（`A=[[0.2,0.1],[0.1,0.3]]` → 影响力 `[0.9412, 1.0588]`），另测了奇异矩阵、
维度不一致、总产出为 0 等异常路径，共 8 条。

## 5. 与工作台的关系：矩阵的行走哪来

当前矩阵的行是经验划分：需求计划 / 采购寻源 / 仓储库存 / 运输物流 / 履约交付 / 合规风控 / 科研流程。

**可以这样用投入产出数据给它补依据**：

1. 把 153 个部门映射到 7 个阶段（如"农业、采矿、电力"→ 上游采购寻源；"交通运输、仓储邮政"→ 运输物流；"批发零售"→ 履约交付）；
2. 按阶段汇总影响力/感应度系数，得到**每个阶段的关联度权重**；
3. 结论用于两个决策：
   - **优先级**：关联度高的阶段先做深智能体（当前履约交付覆盖最全，方向是对的）；
   - **缺口的意义**：矩阵里的 6 个缺口若落在高关联度阶段，其业务影响更大——这比"缺 6 格"更有说服力。

### 阶段映射示意

| 矩阵行 | 对应投入产出部门（示例） | 预期关联特征 |
|---|---|---|
| 需求计划 | 批发零售、居民服务 | 中等前向 |
| 采购寻源 | 农业、采矿、化工、金属冶炼 | 高感应度（被下游拉动） |
| 仓储库存 | 仓储、邮政 | 中等 |
| 运输物流 | 交通运输、仓储邮政 | 高影响力（拉动能源与设备） |
| 履约交付 | 批发零售、居民服务 | 高影响力（贴近最终需求） |
| 合规风控 | 金融、商务服务 | 低直接影响、高传导 |
| 科研流程 | 研究与试验发展、教育 | 长效但短期弱 |

> 这张映射本身也需要真实数据支撑后才能定稿，现在只是**待验证的假设**。

## 6. 局限（必须说明）

1. **示意数据不能当结论**：第 4 节的表只证明算法正确，不构成产业结论；
2. **年度表的滞后性**：基准表每 5 年一次，结构变化快的行业（如新能源）会失真；
3. **部门口径 vs 企业口径**：投入产出表是行业平均，掩盖了企业间差异；
4. **不含服务化/平台化影响**：数字经济部门的核算在传统表里偏弱。
