# 使用说明

> 这套工作台改造自 `luanyujia-workbench` 公开模板（MIT），领域换成了**供应链智能体矩阵**。

## 启动

```bat
cd agentmatrix-sc
dev up                     :: 先起平台（站点 5173 / 接口 8000）

cd agentmatrix-workbench
start.cmd                  :: 起工作台，复用 工作台配置.ini 里 DSH_PORT 指向的 DSH
```

`start.cmd` 是纯 ASCII 的薄壳，真正的逻辑在 `scripts/launch.cjs`（中文提示在那里输出）。

## 五个场景

| 场景 | 干什么 |
|---|---|
| **工作台总览** | 快照 + 待审批（可批可驳）+ 任务列表 + 新建 + 场景助手 |
| **工作流设计** | 拖节点摆位、改参数与连接、校验、发布新版本 |
| **能力矩阵** | 8 阶段 × 4 能力的覆盖与缺口；智能体在线测试、技能试运行 |
| **交付追踪** | 运行监控（点行看步骤）、近 24 小时趋势、死信重试/忽略 |
| **治理与策略** | 调度策略（改权重→试算→保存）、审计日志、工作流校验、告警确认 |

## 面板约定

- 所有面板都是**原生渲染器**（`renderer/am-panels*.js`），不嵌网页；
- 数据经主进程代理（`window.am.get/post/put`），账号与 token 不进渲染层；
- 面板标题栏右侧有「导出 CSV」（表格类）或「导出 PNG/CSV」（趋势图）；
- 点标题栏 **▲** 展开到整屏高度，`Esc` 收起。

## 不用的部分（模板自带，与我们的领域无关）

`harness`（DSH 引擎会话）、`pc-*`（磁盘清理）、`review-*`（自我复盘）、`bl-*`（Blender）、
`site-*`（个人站）等渲染器仍在 `renderers.js` 里，但没有场景使用；
顶栏的市场/捐赠/网页版 AI 入口由 `renderer/retarget.js` 隐藏。
